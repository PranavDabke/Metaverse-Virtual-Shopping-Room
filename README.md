# Metaverse Virtual Shopping Room

A Unity-based metaverse virtual shopping environment featuring immersive 3D navigation, multiplayer-inspired interaction, and virtual shopping experiences.

## Features

- 3D virtual shopping environment
- Interactive room navigation
- Unity game engine implementation
- Real-time immersive experience
- Object placement and environment design
- Virtual metaverse-inspired architecture

## Tech Stack

- Unity 3D
- C#
- Visual Studio
- Unity URP
